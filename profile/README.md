# Swift Intel

Use this organization when you need the x86 architecture reference in Swift: its one package is [swift-x86-standard](https://github.com/swift-intel/swift-x86-standard), which follows its source document as literally as possible. If several specifications govern your subject, use the unifying `swift-*-standard` package in [swift-standards](https://github.com/swift-standards). This is part of Layer 3 of the [Swift Institute](https://github.com/swift-institute).
